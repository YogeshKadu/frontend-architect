# Javascript

Javascript is high level, just in time compiled programming language that conforms to the ECMAScript specification;

## Statements

A statement is a unit of instruction made up of one or more lines of code that represent an action. For example, you can use the following statement to assign a value to a variable named myVariable:

```js
let statement  = "Hey there"
statement = statement + " !"

console.log(statement);
```

## Functions

Js function is a block of code which can be executed when called.
